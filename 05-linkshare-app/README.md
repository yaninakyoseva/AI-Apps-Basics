
# 🔗 LinkShare App

**Course:** AI Apps Basics – SoftUni AI  
**Exercise:** Database Apps with AI Prompts  
**Project:** 01 – Link Sharing App

## 📌 About the Project

LinkShare is a simple web application for sharing and discovering useful links, developed using AI-assisted programming.

The application is connected to Supabase for persistent database storage.

## ✨ Features

- 🔗 Add and share links
- 📝 Add optional descriptions
- 📅 Automatically save creation dates
- 📂 View previously shared links
- 💾 Store links in Supabase
- 🌐 Public access without registration
- 📱 Responsive design

## 🛠️ Technologies Used

- Lovable
- React
- Supabase
- PostgreSQL
- GitHub

## 🗄️ Database Integration

Supabase is used to store application data.

Each link contains:
- `id` – Unique identifier
- `url` – Link address
- `description` – Optional description
- `created_at` – Creation timestamp
