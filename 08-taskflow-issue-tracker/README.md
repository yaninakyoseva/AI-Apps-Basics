## 📌 Project Overview

TaskFlow is an AI-assisted project and issue tracking web application designed to support project organization, issue reporting, and content moderation.

The application introduces role-based access control and administrative workflows inspired by real-world project management systems.

## ✨ Features

### 👀 Visitors
- Browse public projects and approved issues
- Search and filter issues
- View issue details without registration

### 👤 Registered Users
- User registration and login
- Personal profile management
- Submit new issues
- Edit and delete their own issues
- Track issue approval status

### 🛡️ Administrators
- Dedicated admin dashboard
- Create and manage projects
- Approve or reject submitted issues
- Manage reported issues
- Monitor project and issue statistics

### 📸 Issue Management
- Issue title and description
- Project association
- Priority and status tracking
- Content approval workflow
- Optional photo attachments

## 🗄️ Database & Authentication

The application is designed to use Supabase for:

- User authentication
- Project and issue data storage
- Role-based permissions
- Content moderation
- Photo storage

Row Level Security (RLS) is intended to protect user data and administrative operations.
