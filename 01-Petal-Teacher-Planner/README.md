# 🌸 Petal — Teacher Planner

## Project Overview
Petal is a web application prototype designed to help teachers and private tutors organize their teaching activities.

Created during the AI Apps Basics course using Lovable.

## Project Goals
- Design a simple and user-friendly teacher planning interface.
- Explore AI-assisted application development.
- Transform an idea into a working prototype.
- Practice iterative improvements using AI tools.

## Technologies & Tools
- Lovable
- AI-assisted web development

## Live Demo
🌐 [Open Petal Teacher Planner](https://cute-simple-teacherpalnner.lovable.app/)

## Project Status
Initial prototype developed as part of the AI Apps Basics course.

## Key Learnings
- AI-assisted prototyping
- UI/UX design
- Prompt-based development
- Application planning and iteration
