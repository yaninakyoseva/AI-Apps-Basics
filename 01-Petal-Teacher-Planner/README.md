🌸 Petal — Teacher Planner
Project Overview
Petal is a web application prototype designed to help teachers and private tutors organize their teaching activities.
This project was created during the AI Apps Basics course using Lovable, an AI-assisted application development platform.
Project Goals
- Create a simple, user-friendly teacher planning interface.
- Explore AI-assisted web application development.
- Practice transforming an idea into a working prototype.
- Learn how to iterate on an application using AI tools.
