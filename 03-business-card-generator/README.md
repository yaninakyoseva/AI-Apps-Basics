
# Forma - Business Card Generator

## Project Overview

Forma is a modern web application that allows users to design, customize, preview, and export professional business cards.

This project was created as part of the **AI Apps Basics** course at **SoftUni AI**.

The main goal of this exercise was to practice iterative AI-assisted application development, including feature implementation, testing, bug fixing, and UI improvements.

## Live Demo

[Try Forma - Business Card Generator](https://business-card-generator-byforma.lovable.app/)

## Features

- Create personalized business cards
- Enter name, job title, and company name
- Add phone number and email address
- Upload a custom company logo
- Preview business cards in real time
- Customize fonts and colors
- Choose from predefined design themes
- Export business cards as SVG
- Download designs as PNG images
- Responsive and user-friendly interface

## Development Process

The application was developed using an iterative approach:

1. **Initial Implementation**
   - Created the basic business card layout.
   - Added input fields for personal and company details.
   - Implemented a live preview.

2. **UI Customization**
   - Added font customization.
   - Implemented color selection.
   - Introduced predefined design themes.

3. **Logo Integration**
   - Added company logo upload.
   - Integrated uploaded logos into the card preview.

4. **Export Functionality**
   - Implemented SVG export.
   - Added PNG download functionality.

5. **Testing and Improvements**
   - Test short and long text inputs.
   - Check different fonts and colors.
   - Verify logo positioning and scaling.
   - Test SVG and PNG exports.
   - Fix any layout or functionality issues.

## Prompt Engineering Approach

This project focuses on step-by-step AI-assisted development.

The workflow follows:

Idea → AI Prompt → Code Generation → Testing → Bug Fixing → Feature Refinement → Deployment

Instead of implementing everything at once, the recommended approach is to build and improve the application through smaller iterations.
