
# Job Finder by YK - Job Listing Site

## Project Overview

Job Finder by YK is a web application designed to help users explore and manage job opportunities through a simple and intuitive interface.

The project was developed as part of the **AI Apps Basics** course at **SoftUni AI**.

The main objective was to practice step-by-step AI-assisted application development, focusing on implementing, testing, and improving individual features.

## Development Process

This exercise focuses on incremental development rather than generating the entire application with a single prompt.

### Step 1 - Initial Application
- Create the basic job listing interface.
- Add sample job postings.
- Display available jobs.

### Step 2 - Job Categories
- Introduce categories such as IT, Sales, and Marketing.
- Allow users to filter jobs by category.

### Step 3 - Add Job Functionality
- Create a form for adding new job postings.
- Include job title, company, location, job type, description, and requirements.

### Step 4 - Edit Job Functionality
- Allow existing job postings to be modified.
- Update the displayed information.

### Step 5 - Delete Job Functionality
- Add an option to remove job postings.
- Include a confirmation dialog before deletion.

### Step 6 - UI Improvements
- Improve the application layout.
- Add search and filtering options.
- Make the interface responsive.

The project follows an iterative AI-assisted development workflow:

Idea → AI Prompt → Code Generation → Testing → Bug Fixing → Next Feature → Deployment

Each feature can be implemented and tested separately to reduce errors and improve the final application.
