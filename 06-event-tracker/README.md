## 📌 About the Project

Dreamy Event Countdown is a web application designed to help users organize and track upcoming events.

Users can create personal events, manage important dates, and view live countdown timers showing the remaining time until each event.

The application uses Supabase for authentication and persistent database storage.

## ✨ Features

- 📅 Create and manage personal events
- ⏳ Live countdown timers
- ✏️ Edit existing events
- 🗑️ Delete events
- 📝 Add optional event descriptions
- 🔐 User registration and login
- 👤 Personal events for each user
- 💾 Persistent storage with Supabase
- 📱 Responsive user interface

## 🗄️ Database Integration

Supabase is used to store and manage event data.

Each event contains:

- `id` – Unique event identifier
- `title` – Event title
- `date` – Event date and time
- `description` – Optional description
- `user_id` – Event owner

Supabase Authentication provides user registration, login, and logout functionality.
