
# CodeBloom - Barcode Generator & Reader

## Project Overview

CodeBloom is a modern web application that allows users to generate barcodes from text and decode barcode images back into readable text.

This project was developed as part of the **AI Apps Basics** course at **SoftUni AI**.

The goal of this exercise was to practice prompt engineering and AI-assisted application development.

## Features

- Generate Code 128 barcodes from ASCII text
- Upload images to read and decode barcodes
- Download generated barcodes as PNG files
- Copy decoded text to the clipboard
- Clear input fields
- Responsive and user-friendly interface
- Pastel-themed modern design

## Technologies

- Lovable AI
- React
- TypeScript
- AI-assisted development
- Barcode generation and decoding libraries

## Prompt Engineering

The application was created using a structured AI prompt containing:

1. **Instruction** - Build a barcode generator and reader.
2. **Context** - Create a beginner-friendly web application.
3. **Input Data** - Text input and uploaded barcode images.
4. **Output Data** - Generated barcode images and decoded text.
5. **Persona** - Experienced frontend developer and UI/UX designer.

## Testing

The application was tested by:

1. Entering sample text.
2. Generating a barcode.
3. Downloading the barcode as a PNG image.
4. Uploading the generated image.
5. Verifying that the decoded text matches the original input.

**Result:** The generation and decoding workflow works successfully.
